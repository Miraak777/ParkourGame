## Конвенции

- Frontmatter: только `tags`. Статуса заметки нет — он не несёт смысла
- Раздел с одной заметкой — сама заметка с префиксом номера (`06-Параметры.md`); раздел с несколькими — папка с префиксом номера (`07-Дизайн/`)
- Вопросы и прочие колауты — в конце заметки, без отдельного заголовка под них
- Зрелость идеи помечается эмодзи прямо в тексте: 🔴 идея · 🟡 черновик · 🟢 готово
- Новые механики — по [[Шаблон-механики]], новые системы — по [[Шаблон-системы]]
- Все точные числа — только в [[06-Параметры]], ссылка ведёт на конкретный параметр
- Ничего не удаляется по-настоящему: снятое помечаем, причину пишем в [[Журнал-решений]]

### Состояние разделов

Заметки разделов с 05 по 10 несут ещё один тег — состояние:

| Тег | Значение |
| --- | --- |
| `#не_утверждено` | содержание не подтверждено, требует правок |
| `#на_проверку` | утверждения надо проверить в прототипе |
| `#утверждено` | подтверждено, можно опираться |

Правила:

- Ровно один тег раздела, ноль или один вспомогательный, для 05-10 — плюс один тег состояния
- Новый тег не заводим без нужды: два вспомогательных тега из одного раздела обычно означают, что нужна отдельная заметка
- Поиск: `tag:#gameplay` — весь геймплей, `tag:#hazard` — все опасности
- Теги логики (`#система_`, `#механика_`, `#элемент_`) — отдельный слой, словарь в [[03-Термины]]
