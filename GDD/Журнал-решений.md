# Журнал решений

Почему GDD выглядит так, как выглядит. Каждая запись — что изменилось и зачем.

Отсчёт — с текущего состояния. Дальше каждая содержательная правка GDD добавляет запись.

## Итерация 0 — текущее состояние

| Что | Решение | Почему |
| --- | --- | --- |
| Структура | GDD разложен по девяти разделам гайда, каждый раздел — папка | Гайд `Правила тех ДД.md` — источник истины по структуре. Разделы видны на глаз, ничего не теряется в плоском списке |
| Гайд | `Правила тех ДД.md` лежит в GDD как приложение | Это внешний документ, а не часть GDD, но он задаёт его форму |
| Питч | Визитка вынесена в корень репозитория как `README.md`, вне GDD | Отдельный документ, сформированный на основе GDD, для внешних. Своя атмосфера, правила ведения GDD на него не распространяются. `README` — чтобы Git и GitHub показывали его как витрину репозитория |
| Статус заметки | Поле `status` из frontmatter убрано | «Черновик/не черновик» не несёт смысла: полезнее видеть зрелость конкретной идеи, она помечается эмодзи в тексте |
| Слияние заметок | 14 мелких заметок слиты в 7 крупных | Мелкие заметки с одной мыслью не стоили отдельного файла: их всё равно приходилось открывать по цепочке |
| Принципы и референсы | Уехали в раздел «Жанр и синопсис» | «Три кита» и «пять столпов» были одним и тем же списком в двух местах — теперь он один |
| Числа | Всё в `06-Параметры/Параметры.md`, ссылки на конкретный параметр | Параметры меняются в течение разработки, логика — нет. Разделение позволяет крутить значения, не трогая логику |
| Системы и механики | Разделены по гайду: система — правило без условий, механика — логика с условиями | Разные правила описания, разная скорость изменения. Смешивать в одну заметку — значит смешивать два жизненных цикла |
| Зоны | Убраны из состава, оставлен только принцип | Зоны не придуманы. Таблица из семи зон создавала иллюзию готовности |
| Техника | Отдельный раздел `10-Техника` | Гайд описывает содержание игры, а не код. Реализация — приложение, но она нужна каждый день |
| Удалённое | Старые файлы удалены с записью здесь | Содержимое не потеряно: переехало в слияния. Git хранит историю, журнал хранит причины |
| Служебные пояснения | Вынесены из читательских заметок в `AGENTS.md` | Пояснения вроде «это не часть GDD» нужны агенту, а не читателю игры. В заметках осталось только содержание |
| Вид разделов | Раздел с одной заметкой — сама заметка, с несколькими — папка | Папка ради одной заметки — лишний уровень вложенности. Префикс с номером остался у всех разделов, чтобы держать порядок |
| Механики первой версии | Убраны из [[Механики]] в основной текст не идут, факт зафиксирован здесь | Wall climb, Ledge run и Climb пришли из черновика GDD. Условия не проработаны, статус — 🔴 идея. В основном GDD им не место, пока решения нет |
| Завод | «Завод-город» заменено на «старый автономный завод» | Завод — производственная площадка, а не город. Он старый и работает сам по себе, по своим циклам, и ему безразлично, кто по нему бегает |
| Термин «трюк» | Заменён на «механика» по всему GDD | Слово тянуло на цирк с трюками. В документе уже есть раздел «Системы и механики», и механика — точный термин: логика с условиями |
| Платформы и ввод | Платформа — ПК, управление — клавиатура и геймпад | Раньше в GDD всплывал Steam Deck. Теперь платформа одна, и ограничения по кнопкам считаются от геймпада: две кнопки действий плюс два стика, комбинации клавиш не используются |
| Наказание за ошибку | Вопрос оставлен открытым | Раньше документ утверждал, что смерть — часть потока, а не наказание. Это решение, которое ещё не принято, поэтому оно теперь висит вопросом в [[Принципы]] и [[Системы]] |
| Состояние разделов | Заметки разделов 05-10 получили тег состояния | `#не_утверждено`, `#на_проверку` или `#утверждено` — видно, на что можно опираться, а что ещё не решено |
| Метафоры | Список вынесен на суд, тексты пока не переписаны | В стиле игры метафор больше, чем нужно. Решение по каждой — за пользователем, поэтому формулировки пока оставлены как есть |

## Итерация 1 — ощущение, завод, звук

| Что | Решение | Почему |
| --- | --- | --- |
| Ощущение | «Медитативный бег» заменён на напряжённый | Медитативный бег обещает спокойствие, а игра держит на грани ошибки. Напряжение — часть фирмы |
| Передышки | Введены области-передышки между зонами | Без них напряжение не спадает и не читается: ровное напряжение сливается с фоновым шумом. Передышка — часть маршрута, а не пауза |
| Завод | «Заброшенный» заменено на «старый и автономный» | Заброшенный завод противоречит работающим прессам и конвейерам. Завод старый и живёт сам по себе |
| Одушевление завода | Оставлено: «пульс», «живой ритм» | Завод описан как живой организм, и это работает на ощущение. Убирать не будем |
| Звук | Раздел переписан: «Музыка = работа машин» | Идея осталась и стала конкретной: игрок должен слышать, что «музыка» — это работа конкретных механизмов, и соотносить её с их фазами. Дешёвые аналогии (доля, остинато, перкуссия) убраны |
| Конвейер | «Попутный/встречный» и «ветер» заменены на «по движению / против движения» | Направление важнее названия: конвейер по движению разгоняет, против движения тормозит |
| «Чем не является» | Убрано из GDD и из визитки | Анти-позиционирование не нужно: позиционирование уже задано жанром, ощущением и референсами |
| Состояние проекта | Возвращено в паспорт, шкала `прототип → предпродакшн → альфа → бета` | Состояние — паспортный факт. Текущее значение — прототип: по майлстоунам мы на M0 |

## Итерация 2 — решения по содержанию

| Что | Решение | Почему |
| --- | --- | --- |
| Рабочее название | «Паркур на заводе» (Factory Parkour), перенесено в паспорт и заголовки | Имя отвечает на «про что игра» и не спорит с визиткой |
| Ощущение | «напряжённый бег на выживание» → «бег на грани» | Короче и точнее: игра про границу, а не про выживание как таковое |
| Зоны | Зоны — это главы; между ними небольшая локация-перерыв, ничего больше | Хаба нет. Перерыв — часть маршрута, а не структура уровня |
| Новая зона | Определяется новыми механизмами; сюжетное обоснование — возможно, но не обязательно | Механики держат различие зон, сюжет их только оправдывает |
| Наказание за ошибку | Смерть нелицеприятная, с мерзкими звуками; подробное описание подвешено | Направление понятно, конкретика требует изучения референсов — решение принято позже |
| Основной референс | Mirror's Edge | По нему нас будут узнавать; остальные — вспомогательные |
| Арт-стиль | Раздел сведён к открытым вопросам | Содержать пока нечего: решения по стилю не принято, и выдумывать коды рано |
| Термины | Одна таблица, пополняется по ходу; раздела терминов мира не будет | Терминов мира почти нет, а геймплейные появляются вместе с механиками |
| Управление | Раскладка дополнена геймпадом, кнопки прыжка и слайда предложены по стандарту | Прыжок на A/✕, слайд на B/○, спринт на RT/R2 — обычные решения, но пока не утверждены |
| Майлстоуны | Две шкалы: фазы проекта и вехи, закрывающие разделы GDD | Критерий закрытия вехи — раздел переведён в `#утверждено`, то есть проверяемо |

## Итерация 3 — управление, аудитория, требования

| Что | Решение | Почему |
| --- | --- | --- |
| Аудитория | «любители 3D-раннеров от первого лица» | Жанр понятнее вкуса: «бег на грани» — это про ощущение, а аудитория про то, что люди уже играют |
| Спринт | Shift на клавиатуре, работает как переключатель | Отдельная клавиша, спринт не делит кнопку со слайдом. Нажатие включает ускорение, повторное нажатие не выключает; спринт сбрасывается сам при остановке движения |
| Ходьба | Движение по умолчанию, без спринта | Бег был движением по умолчанию, и спринт с ним конфликтовал. Теперь база — ходьба, спринт поверх неё переключателем |
| Геймпад | Утверждены A/✕ на прыжок, B/○ на слайд-присед, RT/R2 на спринт | Обычные решения для геймпада, инвентаря и боя в игре нет, так что остальные кнопки не нужны |
| Таблица стандартной раскладки | Убрана | Своя раскладка зафиксирована целиком, справочная таблица рядом с ней — шум |
| Минимальные требования | Заведено место в [[10-Техника]], таблица пустая | Системные требования нужны для анонса в Steam, но цифры появятся после замеров в прототипе. Вопрос остаётся открытым в паспорте |
| Дубли вопросов | Свёрнуты в отсылки | Полный вопрос живёт в одном месте, остальные заметки на него ссылаются: 13 вопросов → 10 уникальных |
