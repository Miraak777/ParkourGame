> Ядро сеттинга: каждый механизм несёт двойную функцию — парк + угроза.

## По роли

- 🟢 **Инструмент**: платформы, лифты, попутные конвейеры, карусели
- 🔴 **Угроза**: прессы, молоты, дробилки, огненные линии
- 🟡 **Двойного назначения**: кран (мост на 3 секунды / сносит при ошибке), робот-рука (толкает, но её замах — катапульта), кабина лифта (подставка и ловушка)

## По характеру движения

- **Линейные** (вверх-вниз, туда-сюда)
- **Вращательные** (турбины, карусели, замах рычагов)
- **Ритмические** (прессы с периодом — «музыка» уровня)
- **Событийные** (срабатывают от триггера/веса игрока)
- **Глобальные** (меняют всю зону: поворот секции, пульс завода)

## Правила

- Читаемый цикл + постоянный звуковой ритм у каждого элемента
- Соседние элементы либо синхронны, либо в контрапункте — никогда не хаос
- Опасность и путь из одного элемента = глубина: пресс открывает окно прыжка ровно на N кадров

## Идеи

- Пол-конвейер как «ветер», с которым надо считаться
- Поворотная башня: маршруты существуют только в определённых фазах
- «Отбой»: каждые 60 с завод замирает на 5 с (звук предупреждает заранее)
- Зона, где механизмы синхронизированы с музыкой
