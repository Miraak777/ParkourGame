# Майлстоуны

|Фаза|Цель|Критерий готовности|
|---|---|---|
|M0|тестовая арена + базовое движение|«бежать приятно само по себе»|
|M1|паркур: P0-механики + momentum|комбо из 5 трюков без сбоев|
|M2|опасности: 3 типа + телеграфы|тестер «считает» пресс с первого раза|
|M3|вертикальный срез: 15–20 мин|незнакомый игрок проходит|
|M4|демо + страница Steam|чужие люди проходят и хотят ещё|

> [!warning] M0/M1 — блокер всего проекта: если движение «не то» после месяца итераций — пересматривать [[Столпы-дизайна]], а не наращивать контент
