Механики передвижения 
- Ходьба
	* Движение по поверхности
	* Возможен спринт
	* Только на поверхности
	* Возможен прыжок с ускорением вверх
- В воздухе
	* Движение вдоль поверхности с меньшей скоростью
- Спринт
	* Движение по поверхностии
	* Только на поверхности
	* Возможен прыжок с ускорением вверх и в вперёд
- Бег по стене 
	* Движение только вдоль стены в сторону изначального движения
	* Только с острого угла
	* Только в спринте
	* Ограниченная длительность
	* Очень слабая гравитация
	* Возможен прыжок с ускорением в сторону от стены
- Подьём по стене с разгона по земле
	* Движение только вверх по стене
	* только с около-прямого угла 
	* Только в спринте 
	* Только с земли
	* Ограниченая длительность
	* Гравитация выкл
	* Возможен прыжок с ускорением вверх
	
	
- Подьём по спец поверхности(лестницы, рельефная стена) 
	* Отдельное управление 
	* Спец Поверхность
	* Движение только вдоль стены (вверх/вниз/в стороны) 
	* С околопрямого угла
	* гравитация выкл"
	* Возможен прыжок с ускорением в направлении взгляда
- бег вдоль края с зацепом (с противоположной стороны ограждения) 
	* Отдельное управление 
	* Спец Поверхность
	* Движение только вдоль стены вперёд и назад
	* Гравитация выкл
	* Возможен прыжок с ускорением в направлении взгляда
